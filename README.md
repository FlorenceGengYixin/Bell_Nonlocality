# Bell Nonlocality and Hidden-Influence Inequalities

Code accompanying Geng Yixin's Undergraduate Research Opportunities Programme
(UROPS) project on tripartite hidden-influence (HI) inequalities. The project
reproduces the benchmark of Barnea et al. and explores how changing Bob's
settings and outcomes affects the quantum violation and the geometry of the
projected HI polytope.

The notation `[22][324][22]` lists the number of outcomes per setting for
Alice, Bob, and Charlie, respectively. The reference scenario is
`[22][333][22]`.

## Bipartite examples

| Script | Purpose |
| --- | --- |
| [bell_finding.py](bell_finding.py) | Enumerates local deterministic behaviors and converts the vertex representation of the local polytope into inequalities. |
| [bell_classification.py](bell_classification.py) | Groups binary-outcome facets into equivalence classes under local setting and outcome relabelings. |
| [chsh_jordan.py](chsh_jordan.py) | Uses a two-dimensional parametrization motivated by Jordan’s lemma to optimize the CHSH Bell operator. |
| [npa_chsh.py](npa_chsh.py) | Computes CHSH upper bounds at the Q1, Q1+AB, and Q2 levels of the NPA hierarchy. |

## Tripartite scripts

| Task | Entry points |
| --- | --- |
| Reference inequality and HI membership | [tripartite_benchmark.py](tripartite_benchmark.py), [hi_membership_benchmark.py](hi_membership_benchmark.py) |
| Quantum strategy search by see-saw optimization | [Reference scenario](tripartite_seesaw_333.py), [324 extension](tripartite_seesaw_324.py), [444 extension](tripartite_seesaw_444.py) |
| Quantum bounds from NPA relaxations | [npa_333.py](npa_333.py), [npa_324.py](npa_324.py), [NPA notes](README_npa_333.md) |
| HI facet certification and comparison with the local face | [certify_324_facet.py](certify_324_facet.py), [local_dimension_324.py](local_dimension_324.py), [bipartite_locality_324.py](bipartite_locality_324.py) |

See-saw optimization produces achievable values. NPA relaxations give lower
bounds on the quantum minimum, with the reported dual checks performed in
floating-point arithmetic. The facet scripts verify ranks and certificate
conditions using rational arithmetic.

## Quick start

Run from the repository root in a Python 3 environment.

```sh
python -m pip install numpy scipy sympy cvxpy clarabel
python tripartite_benchmark.py
python local_dimension_324.py
python npa_324.py --self-test-only
```

For the bipartite examples:

```sh
python -m pip install "pycddlib>=3"
python bell_finding.py 2 2 2
python bell_classification.py 2 2 2
python chsh_jordan.py
python npa_chsh.py
```

The first two scripts use arguments `MA MB m` for the number of Alice’s
settings, Bob’s settings, and outcomes per setting. Classification currently
supports `m = 2`.

The benchmark evaluates the rounded strategy printed in the paper. Its output
includes positivity diagnostics. Use the reference see-saw script to generate
a feasible strategy.

Use `--help` on the optimization scripts for solver options and input paths.
Some extension scripts use strategy files generated by earlier runs.
